# MarketLens AI

MarketLens AI helps product and marketing teams research a company and its competitors using public web sources.

## What it does

Users enter a company, research focus, and competitors. The application uses FastAPI and LangGraph to plan research, retrieve public sources through Tavily, and generate a structured competitive brief.

## Tech stack

- FastAPI
- LangGraph
- Tavily
- Gemini
- Streamlit

## Limitations

- Uses only public web sources.
- Search snippets may be incomplete or outdated.
- Gemini synthesis may occasionally be unavailable.
- Generated insights require human review.
